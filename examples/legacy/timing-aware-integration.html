Canopi SDK - Timing-Aware Integration

Wayback Machine Insights: This demo showcases the timing fixes discovered during Wayback machine development. The SDK now handles stale state, tab switching, and initialization race conditions that were causing issues.

Timing Issues Solved

The Wayback machine work revealed several critical timing issues:

  • Stale State on Tab Switch: When users switched tabs, the sidepanel showed stale state because it didn't handle TAB_CHANGED messages
  • Race Conditions: Components initialized in wrong order causing dependency failures
  • Missing Refresh Logic: No mechanism to detect and fix stale state automatically
  • Event Timing: Events fired before listeners were ready

Solutions Implemented

1. TabController with TAB_CHANGED Handler

Critical fix: Sidepanel now listens for chrome.runtime.onMessage TAB_CHANGED events and calls refreshFromActiveTab()

2. Timing-Aware Initialization

SDK components initialize in proper dependency order with retry logic and health checks

3. Stale State Detection

Periodic health checks detect when components have stale URLs and automatically refresh

4. Event Synchronization

Debounced and throttled event handlers prevent rapid-fire timing issues

Test Scenarios

Use the timing panel controls to test various scenarios:

  • Force Refresh: Manually refresh all SDK components
  • Simulate Tab Change: Trigger a TAB_CHANGED event to test handling
  • Trigger Stale State: Force components into stale state to test recovery
  • Run Diagnostics: Check current state of all components

Integration Code

// Timing-aware SDK initialization
import { initializeSidebarSDK, TimingUtils } from '@canopi-sdk/sidebar-sdk';

// Initialize with retry logic and health checks
const components = await TimingUtils.safeInitialize(
  () => initializeSidebarSDK({
    enableTabController: true,
    enableMessageListeners: true,
    retryAttempts: 3,
    initializationDelay: 100
  }),
  {
    maxAttempts: 3,
    baseDelay: 200,
    initDelay: 100
  }
);

// Listen for timing events
document.addEventListener('CANOPI_SDK_TAB_CHANGED', (event) => {
  console.log('Tab changed, components refreshed:', event.detail);
});

// Periodic health check
setInterval(() => {
  components.tabController?.forceRefresh();
}, 30000);
