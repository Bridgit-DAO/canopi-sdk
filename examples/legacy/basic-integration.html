What are Smart Tags?

Smart tags are context-anchored annotations that allow users to visualize, annotate, and discuss specific pieces of content on web pages. The Canopi smart tag system implements the "bike rack" architecture with pluggable annotation providers.

This system enables seamless integration between different annotation backends like local storage, Hypothesis, and other collaborative annotation platforms. Users can select text, add notes, apply visual styling, and share insights with others.

Key Features

  • Text Selection: Select any text to create anchored annotations
  • Visual Styling: Apply highlights, underlines, and custom styles
  • Rich Annotations: Add notes, tags, and categorize content
  • Provider System: Sync with multiple annotation backends
  • Non-invasive: Overlay system that doesn't modify host page DOM
  • Event-driven: Integrates seamlessly with canopi ecosystem

Architecture

The Canopi SDK follows a modular architecture with clear separation between core functionality and client applications. The smart tags system is built on several key components:

Core Components

  • SmartTagManager: Central coordination and provider management
  • SelectionOverlay: Non-invasive text selection capture
  • CanonicalUrlService: URL normalization for proxy/direct access
  • PageContextManager: Page navigation and context tracking

Provider System

The pluggable provider architecture allows integration with multiple annotation backends:

  • Local Provider: Browser localStorage (default, always available)
  • Hypothesis Provider: Integration with Hypothesis.is platform
  • Custom Providers: Extensible interface for third-party integrations

Integration with Canopi

This SDK is designed to work seamlessly with the main canopi application. It emits canopi-compatible events and follows the established architectural patterns:

  • Uses canopi ContentAnchor specification
  • Emits CANOPI_SELECTION_CHANGED and CANOPI_ANNOTATION_EVENT events
  • Supports canopi Tab SDK acceptsPageContext contract
  • Compatible with canopi proxy URL handling

Getting Started

To integrate the Canopi smart tags system into your application: 

// Import and initialize
import { SmartTagManager } from '@canopi-sdk/smart-tags';
import { SelectionOverlay } from '@canopi-sdk/overlays';

// Create smart tag manager
const smartTags = new SmartTagManager({
  providers: ['local', 'hypothesis'],
  syncEnabled: true,
  autoSave: true
});

// Initialize selection overlay
const overlay = new SelectionOverlay({
  showToolbar: true,
  enableKeyboardShortcuts: true
});

// Listen for annotation events
document.addEventListener('CANOPI_ANNOTATION_REQUEST', (event) => {
  const { action, selectionData } = event.detail;
  // Handle annotation request
});
